# Web Scraping Using Python

## Project Description
Developed a web scraping application using Python to extract Samsung mobile product information from Flipkart.

## Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas

## Key Features
- Extracts mobile product names.
- Collects product prices.
- Extracts customer ratings.
- Retrieves product image URLs.
- Stores extracted information in a CSV file.

## Project Files
- webscraping.py – Main scraping script.
- mobiles.csv – Extracted mobile product data.
- requirements.txt – Required Python libraries.

## How to Run

1. Install Python.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   python webscraping.py

## Output
The extracted mobile product information is stored in mobiles.csv.
